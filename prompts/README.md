# Prompty systemowe asystenta RAG

Jedna wersja = jeden plik: `v1.md`, `v2.md`, `v3.md` ... Na górze pliku: data, cel zmiany, co poprawia
względem poprzedniej wersji. Min. 3 istotnie różne wersje (wymóg zaliczeniowy).

Nie mylić z dziennikiem promptów użytych do pracy nad projektem: `raport/sections/prompty.tex`.
